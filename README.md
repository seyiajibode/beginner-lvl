# Beginner Python Projects

This repository contains beginner-friendly Python projects to practice programming fundamentals and real-world applications.  
They are selected to be **useful in freelancing and job searches**, showing skills like APIs, web scraping, and automation.

---

## 1. Number Guessing Game (`main.py`)

### 📌 Description  
A simple console-based game where the program randomly selects a number, and the player must guess it.  
Provides hints (`Too Low` / `Too High`) until the correct number is guessed.

### 🚀 How to Run  
```bash
python main.py
```

---

## 2. Simple Web Scraper (`SScraper.py`)

### 📌 Description  
A working starter script for web scraping using **Requests** and **BeautifulSoup**.  
Fetches the page title and all links from a given webpage.

### 🚀 How to Run  
```bash
python SScraper.py
```

## 3. To-Do List CLI (`todo.py`)

### 📌 Description  
A simple command-line app to manage tasks (add, view, delete). Saves tasks to a text file.

### 🚀 How to Run  
```bash
python todo.py
```

### 📝 Features  
- Add, view, and delete tasks  
- Stores tasks in a file (`tasks.txt`)  
- Demonstrates CRUD operations  

---

## 4. Weather Checker (`weather.py`)

### 📌 Description  
Fetches real-time weather data for any city using the **OpenWeather API**.

### 🚀 How to Run  
```bash
python weather.py
```

*(Note: Replace `your_api_key_here` with your own OpenWeather API key.)*

### 📝 Features  
- Calls a live API  
- Parses JSON data  
- Handles invalid input gracefully
